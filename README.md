# PROJECT: VON NEUMANN（プロジェクト：フォン・ノイマン）

2D円形惑星・インクリメンタル工場建設＆恒星系開拓アクションRTS

🎮 **Web版プレイURL (GitHub Pages):**  
**https://wak-shogo.github.io/2Dreplica/**

---

## 概要
- **ハイコンセプト:** 「最初はツルハシ1本、最後は恒星を喰らう機械帝国」
- **エンジン:** Godot Engine 4.7
- **プラットフォーム:** Web (HTML5/WebAssembly) & PC

---

## コアシステム
1. **シームレスな2D円形惑星マップ**:
   - 中心万有引力による滑らかな360度一周歩行
   - 採掘可能な地殻グリッドと不可侵マントルコア
   - レーダースキャナーによる地殻内鉱脈可視化
2. **ハイブリッド軌道物理システム**:
   - プレイヤー機体のリアルタイム重力・大気抵抗シミュレーション
   - リアルタイム軌道予測線（放物線／周回軌道判定）
   - 物理イジェクターの軌道ベイク方式（空中放物線投擲＆ホッパー着弾ロック）
3. **天体バリエーション**:
   - ハビタブル惑星（Terra-01）
   - 低重力・無大気衛星（Luna-01）
   - 完全掘削可能（コアなし）小惑星（Asteroid-Alpha）
   - 楕円軌道の資源彗星（Comet-Peregrine）
4. **4段階進行フェーズ**:
   - Phase 1: サバイバル＆自己強化（採掘、ナノプリンター自己アップグレード）
   - Phase 2: 地上工業化と物理物流（自動採掘ドリル、精錬炉、イジェクター＆ホッパー立体交差）
   - Phase 3: 惑星間進出とドローン革命（月面展開、物流ドローン、マスドライバー）
   - Phase 4: 軌道造船と恒星系征服（軌道シップヤード固定展開、無人戦闘艦隊量産、敵性母艦とのRTS艦隊戦、スペースデブリ引力回収）

## 操作方法
| キー / 操作 | アクション |
| :--- | :--- |
| **[A] / [D]** または **[←] / [→]** | 2D円形惑星の地表を歩行（360度シームレス一周） |
| **[W] / [Space]** または **[↑]** | スラスター噴射（大気圏脱出・軌道投入） |
| **マウス左クリック** | 掘削レーザー（地殻鉱脈の採掘、資源獲得） |
| **[R]** | 地殻断面レーダースキャナー（鉱脈のハイライト表示） |
| **[B]** | 3Dプリンター建築メニュー（ドリル、精錬炉、コンベア、イジェクター、ホッパー、ドローンハブ、マスドライバー、軌道造船所） |
| **[U] / [C]** | Gen 1 内蔵ナノプリンター自己強化メニュー（掘削出力、射程、推力、バッテリー、スキャナー等） |
| **[M]** | 恒星系セクターマップ切り替え（4つのリングゾーン、勢力図、惑星間輸送路線） |
| **マウスホイール** / **[Q] / [E]** | 4段階マルチスケール・シームレスズーム |
| **[1] / [2] / [3] / [4]** または 画面下部 **[P1]〜[P4]** | 各フェーズ即時ジャンプ（Phase 1〜Phase 4） |
| **[H]** | 操作説明パネルの表示切り替え |
| **[ESC]** | メニューを閉じる |
